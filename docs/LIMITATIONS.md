# Limits

Ringlight is an investigation aid, not a certified anti-money-laundering system.

- The default case, sample files, accounts, transfers, amounts, report, freeze, and handoff are synthetic.
- Ringlight does not connect to a bank core, move funds, freeze real accounts, file a regulatory report, or contact a fraud desk.
- Optional CSV or JSON files remain in the current browser session. Nothing is uploaded or stored remotely.
- Risk scores and linked-network detection are deterministic investigation signals. They are not proof of wrongdoing and need human review.
- The two consequential tools change local page state only. They still require separate approvals to demonstrate the control boundary a real integration would need.
- WebMCP is an evolving browser API. Availability depends on the browser host, model, desktop app version, and rollout. The local button remains available when native site tools are not.
